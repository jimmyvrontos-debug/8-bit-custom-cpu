# 8-bit-custom-cpu
8-bit Custom RISC CPU

This repository tracks the development of an 8-bit Custom RISC CPU. The entirety of the project is comprised of the the following files.

8bit_CPU_attempt1.circ: This file contains all the circuits developed-used throughout the project
8-bit Custom RISC CPU.pdf: This is the complete documentation of the entire procedure. It explains this project in detail, showcases the design process, highlights the custom ISA and presents the end product, with the prospect of further development
cpu.py: Assembler-type python script. Developed by claude, it translates the circuits Instruction Set Architecture (ISA to assembly, allowing for complex machine code development and communication with the CPU
sim.py: simple test script to test both the assemblers and CPU's functionality
